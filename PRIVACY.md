# WardVisuals Privacy Policy

WardVisuals provides optional sign-in with a user's own Microsoft account for Minecraft Java Edition authentication.

## Information processed

WardVisuals processes Microsoft OAuth, Xbox, and Minecraft authentication tokens needed to sign in the user and refresh their local session.

## Data storage

Authentication tokens are stored locally on the user's device. WardVisuals does not collect Microsoft passwords and does not transmit tokens to third parties.

## Contact

For privacy questions, contact the project owner through this GitHub repository.
